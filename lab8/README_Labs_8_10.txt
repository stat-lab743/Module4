Labs 8 through 10

This package contains three GitHub Pages lab folders. Each includes:
- index.html: interactive student webpage
- CSV: original analysis dataset
- Word report template: student response document
- Before You Start Word document: jamovi Cloud instructions

Extract the archive, then upload lab8, lab9, and lab10 beside your existing lab6 and lab7 folders. Keep each folder intact so the webpage document-download links work. Do not upload the ZIP itself as the website.

If your repository publishes from main / (root), your URLs follow this pattern:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/lab8/
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/lab9/
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/lab10/

Keep existing repository files and Pages settings. If your publishing source is /docs instead, place the lab folders inside /docs. Use each lab's published URL in the corresponding Canvas assignment or embed.

Students use jamovi Cloud and submit their completed Word report in Canvas. The webpages do not collect, store, or submit answers. Simulation settings are temporary and not saved. Page assets and simulations have no network dependencies; jamovi Cloud itself requires internet access. Word download links require the companion DOCX files to remain beside index.html.

Lab 8 covers Fisher one-way ANOVA, Tukey-adjusted pairwise comparisons, and eta-squared. Lab 9 covers Pearson correlation and the limits of causal inference. Lab 10 uses the same practice-hours dataset to teach simple linear regression, residuals, uncertainty, and extrapolation.

Statistics, CSV download consistency, simulation calculations, controls, keyboard interaction, document links, and mobile layout were checked. The Word report questions were checked against the webpages. Automated DOCX rendering is unavailable in the authoring environment; preview page breaks in Word before distributing the documents.

Numerical answer keys are intentionally excluded from student packages.
